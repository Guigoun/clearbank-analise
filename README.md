# Análise Financeira com Python — ClearBank

## Descrição do Projeto

Este projeto tem como objetivo realizar a leitura,
validação e análise de transações financeiras
a partir de um arquivo CSV.

O sistema identifica registros inválidos, calcula
métricas financeiras mensais, sinaliza transações
potencialmente suspeitas e gera relatórios em JSON.

## Tecnologias utilizadas

- Python
- CSV
- JSON
- datetime
